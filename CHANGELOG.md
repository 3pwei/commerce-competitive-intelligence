# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project
uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-22

### Added

- Provider-neutral product capture, retailer parsing, review analysis, and recommendation boundaries.
- Offline STG, ODS, TGT, Comment, Overall Trend, and Recent Suggestion outputs.
- Deterministic fixture/mock Demo with validation, evidence, Email preview, and n8n orchestration.
- Unit, contract, integration, coverage, dependency, and secret checks.
- Public architecture, runbook, sanitized example artifacts, and release documentation.

### Security

- Credentials, live captures, local configuration, generated output, and personal identifiers are
  excluded from version control and checked by CI.
