# v1.0.0 — Portfolio Release Draft

## Highlights

- Runs an end-to-end competitive intelligence Demo offline with public fixtures and deterministic
  mock providers.
- Produces six Google Sheets-compatible datasets covering staging, normalized observations,
  business targets, review findings, detected trends, and recommended actions.
- Keeps business facts deterministic and evidence-backed while isolating replaceable LLM, scraping,
  Sheets, and Email integrations.
- Includes a Manual Trigger n8n workflow with dry-run defaults, SEQN duplicate protection, optional
  Google Sheets append, and optional Gmail delivery.

## Reproduce

```bash
python -m pip install -e ".[dev]"
python -m competitive_intelligence demo-run \
  --mode fixture --provider mock --output-dir output/demo
```

Open `output/demo/validation_report.json` and confirm `status` is `passed`. The six JSON/CSV pairs
are under `output/demo/sheets`, and `email_preview.html` is safe to open locally.

## Verification

- Ruff lint and format
- Mypy strict mode
- Pytest with at least 85% coverage
- Offline end-to-end Demo
- Dependency audit and Gitleaks
- Six Sheet schema/order and cross-sheet reconciliation checks

## Known limitations

This release has no scheduler, database, resident API, dashboard, or Production deployment. Public
fixtures are synthetic and are not current retailer data. External integrations require operator-
managed credentials and deliberate opt-in.

## Release procedure after PR acceptance

1. Confirm the PR checks are green and squash-merge it.
2. Run the documented offline Demo from a clean checkout of `master`.
3. Create annotated tag `v1.0.0` at the verified merge commit.
4. Create the GitHub Release using this file as the body.
5. Attach no credentials, raw captures, local output, or personal identifiers.

This file is a draft; PR #12 intentionally does not create the tag or Release.
